# Named threads

Find the threads that matter by their titles, across every channel you have joined.

## Getting started

1. Open **Threads** from the navigation, or press Cmd+Shift+H (Ctrl+Shift+H on Windows and Linux).
2. Threads with a title are listed newest activity first. Choose one to open it beside its channel.
3. Use the channel menu to show one channel's threads.
4. Choose **Rename** to edit a title in place: press Enter to save or Escape to cancel. Choose **Clear title** to remove it.

Titles are shared with everyone in the channel. Agents and the `buzz` CLI set them with `buzz threads title set`, and Buzz 0.x shows the same titles. The list updates as titles change and replies arrive.
