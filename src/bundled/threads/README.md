# Named threads

See a thread's title wherever the thread shows.

## Getting started

1. A titled thread shows its title under its first message in the channel. Choose the title to open the thread.
2. An open thread's tab shows its title. Rename the tab to set the title for everyone in the channel.

Titles are shared with everyone in the channel. When you start a thread by mentioning agents, the first one you mention names it with its `thread_title` tool; the `buzz` CLI sets them with `buzz threads title set`, and Buzz 0.x shows the same titles.
